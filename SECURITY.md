# Security policy

Do not report a vulnerability in a public Issue, pull request, Discussion, commit, or test fixture.
Use GitHub private vulnerability reporting for this repository. If that channel is unavailable,
email security@sangrep.com with the repository name and a minimal reproduction.

Do not include real credentials, private documents, raw provider payloads, local databases, or
customer material. Supported-version claims begin only with an explicit release; this governed
foundation has no supported release.
