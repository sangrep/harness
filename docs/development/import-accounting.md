an extractive fake provider, provider replay, JSON/JSONL CLI, typed safe failures,
examples and developer docs. Safety regressions additionally constrain every answer
line, all tool-result payloads, non-finite deadlines and token checks before tools.

The original sanitized adaptation excerpts remain inspectable under
`provenance/import/adaptation`. Product-specific preflight, routing, pricing,
persistent storage and live protocol branches are not activated by substituting
permissive values. The headless reference profile supplies explicit current grant,
request and protocol authority, and includes only memory stores and fake/replay
transports. The broader live protocol branch remains an adaptation input, not a
qualified runtime transport.

No storage crash/reopen tests, live V2 qualification, production credential or vault
implementation, pricing policy, rich-document parser or product integration is
claimed. An atomic Python memory implementation is not production durability.

and the caught provider-failure persistence port. Destination integration preserves
