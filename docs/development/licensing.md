# Licensing and provenance

Approved intent is `AGPL-3.0-or-later OR LicenseRef-Sangrep-Commercial`. The latter
means a separate Sangrep commercial agreement, not an automatic entitlement. The
repository's `LICENSE` remains the authority for the current publication gate.

Package metadata records that intent. It does not assert that specialist legal
review, contributor rights, copyright ownership or publication acceptance has been
completed. Contributor terms remain subject to the repository governance process;
no new assignment, CLA or rights warranty is invented by this implementation.

New repository-owned code and synthetic fixtures are classified separately from
reviewed one-time imported engine source. Import provenance must identify the
sanitized inventory and digests without including private source identifiers or
history. The public `sangrep-contracts` dependency is Apache-2.0 and is consumed as
a separate digest-verified artifact. It is not copied into this distribution.

The license/provenance check verifies technical inventory and consistency. It does
not substitute for specialist legal or contributor-rights acceptance.
