# Governance

Maintainers own scope, security, compatibility, release, and public-information decisions for this
component. Changes should be reviewable, reversible, independently checked, and limited to this
repository's public contract.

One maintainer approval and the required repository check are the minimum merge gate. Security,
license, compatibility, and release changes may require additional named review. Public history is
permanent; maintainers must remove private context before a branch, Issue, pull request, review,
workflow log, artifact, or release is created.
