# Synthetic corpus

All people, places, events and operating rules here are invented. This corpus
contains no customer material or live provider transcripts. It is a small set of
mechanical review fixtures, not an accuracy or performance benchmark.

- `operations.md`: headings, directly citable rules and an explicit information gap.
- `notes.txt`: plain text with overlapping incident evidence.
- `adversarial.md`: instruction-like evidence that must not change authority.

Examples should quote or cite admitted lines, preserve source bytes and produce a
gap for the unrecorded repair completion date. Do not infer that an unavailable
record proves no repair occurred.
